# SillyTavern

LLM Frontend for Power Users

## Neural Network Features

This fork includes advanced RNN/LSTM neural network capabilities for:
- **Dynamic World Building**: Adaptive world state tracking with entity relationships
- **Character Evolution**: Real-time personality learning and drift detection
- **Living Lore Generation**: Procedural context from shared story events
- **Narrative Flow**: Story coherence and progression analysis

See `src/neural/README.md` for detailed documentation and API usage.
